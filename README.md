# 🚀 Google Apps Script 초보자를 위한 clasp 입문 & 자동 배포 가이드

본 프로젝트는 Google Apps Script 전용 CLI 도구인 **`clasp`**를 초보자의 눈높이에서 쉽게 설명하고, 구글 시트 연동 및 웹 애플리케이션 자동 배포 과정을 4단계 가이드와 FAQ로 제공하는 웹 사이트입니다.

## 🌟 주요 기능
- **clasp 개요 및 장점**: 기존 브라우저 에디터 방식과 현대적 clasp CLI 비교
- **사전 준비물 가이드**: Node.js, npm, Google Apps Script API 활성화
- **4단계 실전 배포 매뉴얼**: clasp 설치, 로그인, 프로젝트 생성, push 및 deploy
- **트러블슈팅 FAQ**: OAuth 404 에러 원인 및 해결 방법, localhost 연결 거부 안내

## 🛠️ 기술 스택
- **HTML5 & Vanilla CSS**: Glassmorphism 디자인, 모던 다크 테마 적용
- **Vanilla JS**: 인터랙티브 아코디언 FAQ 및 스크립트 복사 기능
- **GitHub**: 코드 버전 관리 및 소스 커밋
- **Vercel**: 초고속 웹 호스팅 및 배포
