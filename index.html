clasp란 무엇인가요?

clasp는 Command Line Apps Script Projects의 약자로, 구글(Google) 공식 팀에서 개발한 터미널 기반 앱스 스크립트 관리 도구입니다.

기존에는 구글 웹 브라우저 에디터(script.google.com)에 일일이 접속해서 코드를 타이핑해야 했지만, clasp를 사용하면 내 컴퓨터의 VS Code 에디터에서 자유롭게 코딩하고 명령어 한 줄로 구글 시트 및 웹앱에 업로드 및 배포할 수 있습니다.

❌ 기존 브라우저 에디터 방식

  • ⚠️ 인터넷이 연결된 브라우저 창에서만 수정 가능
  • ⚠️ 코드 자동 완성 및 단축키 기능 제한적
  • ⚠️ Git / GitHub 버전 관리 불가능
  • ⚠️ 여러 파일 관리 및 팀 협업이 번거로움

✅ clasp 활용 현대적 방식

  • ✨ 내 컴퓨터의 VS Code / IDE에서 편하게 개발
  • ✨ 강력한 코드 자동 완성 및 TypeScript 지원
  • ✨ Git & GitHub로 백업 및 버전 관리 100% 가능
  • ✨ 터미널 명령어로 1초 만에 코드 푸시 및 웹앱 배포
⚙️

사전 준비물

1. Node.js & npm 설치

clasp는 Node.js 패키지이므로 컴퓨터에 Node.js가 설치되어 있어야 합니다. 터미널에서 설치 여부를 확인해보세요.

Terminal 
node -v
npm -v

2. Apps Script API 활성화

구글 계정 설정에서 외부 CLI 접근을 허용해야 합니다. (최초 1회 필수)

🔗 script.google.com/home/usersettings에 접속하여 Google Apps Script API 설정을 ON(사용)으로 변경하세요.
🛠️

clasp 실전 활용 4단계 가이드

clasp 설치 및 구글 계정 로그인

터미널에 아래 명령어를 입력하여 clasp를 전역(Global)으로 설치하고 구글 계정에 로그인합니다.

Terminal 
# 1. clasp 전역 설치
npm install -g @google/clasp

# 2. 구글 계정 로그인
clasp login

* `clasp login` 실행 시 브라우저 창이 열리며 구글 계정 승인을 진행하게 됩니다.

구글 시트 & 스크립트 프로젝트 생성 (`clasp create`)

프로젝트 폴더를 생성하고 구글 스프레드시트 연동 스크립트를 만듭니다.

Terminal 
# 프로젝트 폴더 생성 및 이동
mkdir my-gas-app && cd my-gas-app

# 구글 시트 연동 스크립트 신규 생성
clasp create --type sheets --title "학생 순위 관리 앱(2026)"

* 생성 후 폴더 내에 `.clasp.json`과 `appsscript.json` 파일이 자동 생성됩니다.

코드 작성 및 구글로 업로드 (`clasp push`)

`Code.gs` 및 `Index.html` 파일에 코드를 작성한 후 구글 서버로 업로드합니다.

Terminal 
# 내 컴퓨터의 소스코드를 구글 서버로 업로드
clasp push -f

웹 애플리케이션으로 공개 배포 (`clasp deploy`)

작성한 스크립트를 최종 라이브 웹 앱 URL로 공개 배포합니다.

Terminal 
# 웹 애플리케이션 최종 배포
clasp deploy --description "v1.0 배포"

# 배포된 웹 앱 브라우저에서 바로 열기
clasp open --webapp
❓

자주 묻는 질문 & 트러블슈팅

Q1. 배포된 웹 앱 링크를 클릭했는데 '404 현재 파일을 열 수 없습니다'라고 뜹니다.

구글 보안 정책상 CLI(`clasp`)로 새로 생성된 프로젝트는 **최초 1회 계정 소유자가 에디터에서 권한 승인**을 해주어야 배포 URL이 활성화됩니다.

💡 해결법: `clasp open`으로 앱스 스크립트 에디터를 열고 상단 [배포] > [새 배포] > [웹 앱]을 선택하여 권한 승인(Review Permissions) 및 배포를 1회 완료하면 바로 정상 작동합니다.
Q2. `clasp login` 시 브라우저에서 '연결을 거부했습니다(localhost)'라고 나옵니다.

지극히 정상적인 결과입니다! 8888번 포트 수신 웹서버가 연결되지 않아 발생하는 화면이지만, 브라우저 맨 위 주소창(URL)에는 `http://localhost:8888/?code=4/0AV...` 형태로 인증 코드가 포함되어 있습니다.

그 주소창 URL 전체를 터미널에 붙여넣으시면 로그인이 완료됩니다.

Q3. Git과 clasp를 함께 사용할 때 `.gitignore` 설정 방법은?

개인 구글 인증 정보가 담긴 `.clasprc.json`이나 프로젝트 설정 파일 중 비밀번호 등이 들어갈 수 있으므로 `.gitignore`에 아래 항목을 추가하는 것이 안전합니다.

.clasprc.json
node_modules/
.env
