Google Apps Script CLI

clasp 입문 및 자동 배포 가이드

브라우저를 벗어나 내 컴퓨터에서 앱스 스크립트를 작성하고 터미널 명령어 한 줄로 구글 시트에 자동 배포하는 완벽 매뉴얼

01.

clasp란 무엇인가요?

clasp (Command Line Apps Script Projects)는 구글 공식 개발팀이 제공하는 앱스 스크립트 전용 터미널(CLI) 개발 도구입니다.

구글 웹 에디터(`script.google.com`)를 직접 열지 않고도, 개인 컴퓨터의 VS Code 등 원하는 에디터에서 코드를 작성한 뒤 터미널 명령어로 구글 시트에 푸시 및 웹앱 배포를 완료할 수 있습니다.

기존 웹 에디터 방식

  • • 브라우저 창에서만 코드 편집 가능
  • • Git / GitHub 코드 버전 관리 불가능
  • • 자동 완성 및 단축키 기능 제한적

clasp CLI 현대적 방식

  • • VS Code 등 로컬 IDE에서 개발
  • • Git 및 GitHub 백업 100% 연동
  • • 터미널 명령어로 1초 만에 자동 푸시
02.

사전 준비사항

1. Node.js 확인

clasp 실행을 위해 컴퓨터에 Node.js가 설치되어 있어야 합니다.

Terminal 
node -v
npm -v

2. API 활성화 (최초 1회)

구글 계정에서 외부 CLI 연동 권한을 켜주어야 합니다.

🔗 script.google.com/home/usersettings 접속 후
Google Apps Script API를 ON(사용)으로 변경합니다.
03.

4단계 배포 매뉴얼

1

clasp 설치 & 구글 계정 로그인

터미널에서 clasp를 설치하고 내 구글 계정을 연동합니다.

bash 
# clasp 전역 설치
npm install -g @google/clasp

# 구글 로그인 (브라우저 인증 진행)
clasp login
2

스프레드시트 & 프로젝트 생성

프로젝트 폴더를 생성하고 구글 시트 연동 스크립트를 새로 만듭니다.

bash 
# 폴더 생성 후 이동
mkdir my-ranking-app && cd my-ranking-app

# 구글 시트 연동 스크립트 생성
clasp create --type sheets --title "학생 순위 관리 앱(2026)"
3

코드 작성 및 업로드 (`clasp push`)

`Code.gs` 및 `Index.html` 코드를 올립니다.

bash 
# 내 컴퓨터의 코드를 구글 서버로 업로드
clasp push -f
4

웹 애플리케이션으로 공개 배포

스크립트를 라이브 웹 앱 URL로 최종 공개 배포합니다.

bash 
# 웹 앱 버전 배포
clasp deploy --description "v1.0 배포"

# 웹 앱 URL 브라우저에서 확인
clasp open --webapp
04.

트러블슈팅 & 자주 묻는 질문

Q1. 웹 앱 URL을 열었는데 '404 현재 파일을 열 수 없습니다'라고 나옵니다.

구글 보안 정책상 CLI로 생성한 **신규 프로젝트는 최초 1회 계정 소유자가 에디터 화면에서 직접 접근 권한 승인**을 완료해야 외부 `/exec` URL이 활성화됩니다.

💡 해결법: `clasp open` 명령어로 에디터를 열고 [배포] > [새 배포] > [웹 앱]을 선택하여 권한 승인(Review Permissions)을 1회 진행하시면 즉시상태가 활성화됩니다.
Q2. `clasp login` 시 'localhost 연결을 거부했습니다'라는 결과가 나옵니다.

지극히 정상적인 과정입니다! 수신 서버 포트 미연결로 표시되지만, 브라우저 주소창(URL)에는 `http://localhost:8888/?code=4/0AV...` 형식으로 인증 코드가 포함되어 있습니다.

해당 주소 전체를 복사하여 터미널에 전달하시면 로그인이 정상 완료됩니다.

Q3. Git으로 소스코드 관리 시 주의할 점은 무엇인가요?

개인 구글 토큰이 저장되는 `.clasprc.json` 파일이 Git에 포함되지 않도록 `.gitignore` 파일에 반드시 등록해 주셔야 합니다.

.clasprc.json
node_modules/
